PEMBAGI KELOMPOK OTOMATIS

Aplikasi web ringan berbasis Single Page Application (SPA) untuk mengacak dan membagi daftar nama dari file teks (.txt) menjadi beberapa kelompok secara adil dan otomatis.

Live Demo: https://mahengror.github.io/Group-Randomness/

Fitur Utama
1. Upload file (.txt) secara instan.
2. Pengacakan sangat adil! Tidak ada istilah "disetting".
3. UI yang bersih dan elegan serta mendukung mobile maupun dekstop.
4. Semua privasi mu aman.

Cara Penggunaan
1. Siapkan file teks (.txt) yang berisi nama nama dengan format satu nama per baris.
2. Buka aplikasi web melalui link Live Demo di atas.
3. Klik area Upload File atau seret file (.txt) Anda ke dalam kotak yang disediakan.
4. Cek kembali daftar nama yang muncul di layar.
5. Masukkan jumlah kelompok yang ingin Anda buat di kolom input.
6. Klik tombol "Bagi Kelompok".
7. Selesai!
