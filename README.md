PEMBAGI KELOMPOK OTOMATIS

Aplikasi web ringan untuk mengacak dan membagi daftar nama dari file teks (.txt) menjadi beberapa kelompok secara otomatis.

Live Demo: https://mahengror.github.io/Group-Randomness/

Fitur Utama
1. Upload file (.txt) secara instan.
2. Pengacakan sangat adil, tidak ada istilah "di-setting".
3. UI yang bersih dan simpel serta mendukung mobile maupun dekstop (hopefully).
4. Semua privasi aman.

Cara Penggunaan
1. Siapkan file teks (.txt) yang berisi nama nama dengan format satu nama per baris.
2. Buka aplikasi web melalui link Live Demo di atas.
3. Klik area Upload File atau seret file (.txt) Anda ke dalam kotak yang disediakan.
4. Masukkan jumlah kelompok yang ingin Anda buat di kolom input.
5. Klik tombol "Buat Kelompok".
6. Selesai, tinggal salin hasilnya!
